# 本地 USB/串口 通信测试指南

要在没有真实 ECU 硬件的情况下测试 USB 通信功能，您可以使用虚拟串口软件配合模拟脚本。

## 1. 安装虚拟串口软件

您需要创建一个虚拟串口对（例如 `COM1` <-> `COM2`）。这两个端口是互通的，连接到 `COM1` 的程序发送的数据会被连接到 `COM2` 的程序接收，反之亦然。

推荐软件：

- **Windows**: [com0com](http://com0com.sourceforge.net/) (开源) 或 Virtual Serial Port Driver (商业)
- **Linux**: `socat` 命令

## 2. 运行模拟 ECU 脚本

我们提供了一个 Node.js 脚本来模拟 ECU 的行为。它会连接到一个串口，并定期发送引擎状态数据（RPM, TPS 等）。

在项目根目录下运行：

```bash
# 假设您的虚拟串口对是 COM1 和 COM2
# 我们将模拟脚本连接到 COM2
node scripts/mock-ecu.js COM2
```

脚本启动后，会显示 `Mock ECU connected to COM2`。

## 3. 在应用中连接

1. 启动 ECU 管理系统应用 (`npm run dev`)。
2. 在应用顶部的串口选择下拉框中，应该能看到 `COM1`（如果虚拟串口驱动安装正确）。
3. 选择 `COM1` 并点击连接图标。
4. 您应该能看到仪表盘上的数据开始跳动，这表示应用成功接收到了模拟脚本发送的数据。
5. 您也可以尝试在应用中修改参数并保存，观察 `mock-ecu.js` 的控制台输出，确认应用是否成功发送了数据。
